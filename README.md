# Ionosonde data mirror

`stations.json` is an unmodified copy of https://prop.kc2g.com/api/stations.json,
refreshed every 15 minutes for the HF Range Planner (non-commercial).

The measurements come from the Global Ionospheric Radio Observatory (GIRO),
via the Lowell GIRO Data Center (https://giro.uml.edu/) and its participating
station operators, aggregated by KC2G (https://prop.kc2g.com/).
